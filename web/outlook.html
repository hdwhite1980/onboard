Connect your installed Onboard app

In Onboard → AI Settings, sign in to the same Microsoft account, then create a pairing code for this application. This connects the add-in to your local AI; it does not grant Microsoft access. AI Settings can automatically detect your configured Microsoft tenant environment. The code has no time limit and can be used once; creating another code replaces it.
